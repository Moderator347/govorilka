# 📖 ЭмоЧиталка — «эмоциональная» читалка электронных книг

Веб-приложение: загружаете электронную книгу, а она **озвучивается с эмоциями**,
соответствующими содержанию текста. Каждый фрагмент книги анализируется на
эмоциональную окраску, и синтез речи стилизуется под неё — тон, темп, громкость,
дрожь, вибрато.

```
Загрузка книги → разбор (EPUB/FB2/TXT/MD/HTML) → сегментация на фрагменты
→ определение эмоции каждого фрагмента → эмоциональный TTS-синтез (Piper + DSP-просодия)
→ MP3 по каждому фрагменту → плеер в браузере с текстом и «эмоциональными бейджами»
```

## Возможности

- **Форматы:** EPUB, FB2, TXT, Markdown, HTML (до `MAX_UPLOAD_MB`, по умолчанию 60 МБ).
- **10 эмоций:** `neutral, happy, sad, angry, fear, excited, tender, mysterious, heroic, ironic`.
- **Детекция эмоций:** лексический анализатор + пунктуационные/структурные признаки
  (восклицания, КАПС, многоточия, диалоги, длина предложений), с учётом эмоции
  предыдущего фрагмента. Опционально — точный ИИ-анализ через любой
  OpenAI-совместимый API (переменные `EMOTION_API_KEY` / `EMOTION_API_BASE` / `EMOTION_MODEL`).
- **Эмоциональная просодия** поверх базового голоса Piper (локальный нейросетевой TTS):

  | Эмоция | Тон | Темп | Громкость | Дрожь / вибрато |
  |---|---|---|---|---|
  | радость   | +2.5 ст | быстрее | + | лёгкое вибрато |
  | восторг   | +3.8 ст | заметно быстрее | + | сильное вибрато |
  | грусть    | −2.6 ст | медленнее | − | дрожь (tremolo) |
  | гнев      | −1.3 ст | быстрее | ++ | слабая дрожь |
  | страх     | +1.7 ст | быстрее | − | сильная дрожь + вибрато |
  | нежность  | +1.1 ст | медленнее | − | мягкое вибрато |
  | тайна     | −1.7 ст | медленно | − | слабая дрожь |
  | героика   | −0.9 ст | размеренно | ++ | — |
  | ирония    | +0.7 ст | чуть медленнее | ± | вибрато |

  Интенсивность эффектов масштабируется уверенностью детекции.
- **Интерфейс:** drag-and-drop загрузка, библиотека книг, прогресс обработки
  в реальном времени, последовательное воспроизведение, подсветка текущего
  фрагмента и его эмоции, пропуск ещё не озвученных кусков.
- **Всё локально:** книга и голос не покидают вашу машину
  (если не включён LLM-анализ).

## Быстрый старт

Требуется Python 3.10+ и `ffmpeg` (для кодирования в MP3).

```bash
pip install -r requirements.txt

# Если весов модели нет — скачайте голос Piper:
mkdir -p models && cd models
wget https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/lessac/medium/en_US-lessac-medium.onnx
wget "https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/lessac/medium/en_US-lessac-medium.onnx.json?filename=en_US-lessac-medium.onnx.json"
cd ..

uvicorn app.main:app --host 0.0.0.0 --port 8000
# откройте http://localhost:8000
```

## Структура проекта

| Модуль | Роль |
|---|---|
| `app/books.py` | Парсинг форматов, извлечение метаданных, сегментация на «пассажи» (~45 слов) |
| `app/emotion.py` | Детекция эмоций (правила/лексика + опциональный LLM), профиль просодии |
| `app/tts.py` | Синтез Piper + DSP-эффекты: pitch-shift, WSOLA time-stretch, tremolo, vibrato, лимитер |
| `app/main.py` | FastAPI: REST API, фоновый конвейер обработки, раздача аудио, статика SPA |
| `static/` | Фронтенд (vanilla JS SPA): загрузка, библиотека, плеер |
| `models/` | ONNX-голос Piper |
| `data/` | Загруженные книги и готовое аудио (создаётся автоматически) |

### API

- `POST /api/books` — загрузка файла (multipart), старт фоновой обработки
- `GET /api/books` — список книг со статусами/прогрессом
- `GET /api/books/{id}` — книга, фрагменты, эмоции, готовность аудио
- `GET /api/books/{id}/audio/{index}` — MP3 фрагмента (`425`, если ещё не готов)
- `DELETE /api/books/{id}` — удалить книгу
- `GET /api/emotions` — список эмоций

Обработанные книги хранятся в `data/<id>/` (исходник, `meta.json`, MP3);
они переживают перезапуск сервера.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PIPER_MODEL` | `models/en_US-lessac-medium.onnx` | путь к голосу Piper |
| `MAX_UPLOAD_MB` | `60` | лимит размера загрузки |
| `MAX_PASSAGES` | `400` | максимум озвучиваемых фрагментов на книгу |
| `EMOTION_API_KEY` | — | ключ OpenAI-совместимого API для LLM-анализа эмоций |
| `EMOTION_API_BASE` | `https://api.openai.com/v1` | endpoint LLM |
| `EMOTION_MODEL` | `gpt-4o-mini` | модель LLM |

## Защита от OOM (exit code 137)

Ранее длинный «грустный» фрагмент мог убить процесс нехваткой памяти.
Исправлено в `app/tts.py` и `app/main.py`:

1. **Попредложенный синтез:** пассаж озвучивается предложение за предложением,
   DSP-эффекты применяются к коротким блокам, буферы освобождаются сразу.
2. **Память-безопасный pitch-shift:** `resample_poly` вызывается с малыми целыми
   `up/down` (`Fraction.limit_denominator(97)`). Прежде фильтр scipy строился с
   коэффициентами порядка `sr*100` и на одном вызове аллоцировал сотни мегабайт
   (float64-массивы на десятки миллионов элементов) — именно это и убивало процесс.
3. **WSOLA без больших матриц:** time-stretch реализован покадрово с ограниченным
   поиском вместо векторизованных `[F,S]`/`[V,win]` матриц кандидатов.
4. **Очередь в один поток:** книги обрабатываются последовательно общим
   `ThreadPoolExecutor(max_workers=1)` — параллельные загрузки не умножают память.
5. **Грациозная деградация:** `MemoryError` перехватывается, книга помечается с
   понятной ошибкой, уже готовые фрагменты сохраняются и остаются доступными.

Тест: фрагмент на 1040 слов (~287 с аудио) при жёстком лимите адресного
пространства 1.6 ГБ проходит с пиковым RSS ~0.6 ГБ (раньше — гарантированный
OOM-kill процесса).

## Известные ограничения

- Базовый голос говорит **по-английски** (en_US-lessac). Русский текст будет
  прочитан транслитерацией — для русского подключите русскую модель Piper
  (например, `ru_RU-midia-medium`) через `PIPER_MODEL`.
- Лексикон эмоций англоязычный; для точного анализа русской прозы включите
  LLM-режим (`EMOTION_API_KEY`).
- Первый запрос после старта медленнее — лениво загружается ONNX-модель.
